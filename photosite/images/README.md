Put your photos in this folder.

The site currently points at placeholder images (picsum.photos) inside `index.html`.
Replace those `src` URLs with paths like `images/your-photo.jpg` once you drop your
own files in here, and update the matching `alt` text for each one.

Recommended: export web-sized JPGs (long edge ~2000px, ~80% quality) to keep the
site fast to load.
